Why this blog ?

Sharing experiments and ideas

This blog has been created to share experiments and ideas, a sandbox to document key concepts around platform teams and distributed systems:

  • Platform as product mindset
  • DevEx : Measuring/Improving developer’s productivity:
    • Eliminate frictions
    • Reduce cognitive loads
    • Increase Flow
  • Continuous Customer Discovery as a way to keep focusing efforts in high value/in-demand platform’s features
  • Nudging as a way to promote and teach best practices (through scorecards)
  • Ways to provide more autonomy to platform’s team when considering large scale technical migrations involving updating micro-service’s application code (in different languages), to make it compatible with new infrastructure
  • Internal Developer Portal / Adoption / Autonomy / Self service
  • PDCA and the way of the prompt or / context engineering + feedback loop when using LLMs to update code at scale.
